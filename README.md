# ✨ FEATURES & PLUGINS

## ⚙️ System & Bot Tools

* `alive` — Check bot status.
* `menu` — Display the available commands.
* `ping` — Monitor live response speed.
* `uptime` — Check bot uptime and resources.
* `owner` — Show owner information.
* `online` — Check online/presence information.
* `getjid` — Get WhatsApp Channel JID.
* `pair` — Get the SANA MD MINI pairing code.

---

## 🛡️ Security & Automation

* `antidelete` — Enable/disable anti-delete.
* `anti-call` — Automatically handle/reject calls.
* `autobio` — Automatically update WhatsApp bio.
* `autorecording` — Control auto-recording behavior.
* `autotyping` — Control auto-typing behavior.
* `autoread` — Control automatic read behavior.
* `autoviewsview` — Control automatic status-view behavior.
* `autelikestatus` — Control automatic status-like behavior.

---

## 👥 Group Management

* `requestlist` — View pending group join requests.
* `acceptall` — Accept pending group requests.
* `rejectall` — Reject pending group requests.
* `kick` — Remove a group member.
* `kickall` — Remove multiple members.
* `removeadmins` — Remove admin privileges.
* `promote` — Promote a member.
* `demote` — Demote an admin.
* `botadmin` — Check bot admin status.
* `add` — Add a member.
* `addmember` — Add a member to the group.
* `tagall` — Tag all group members.
* `hidetag` — Tag members without displaying mentions.
* `admincheck` — Check admin status.
* `atall` — Control @all permissions.
* `end` — End/close group-related action.
* `leave` — Make the bot leave a group.
* `groupstatus` — Post text/media to WhatsApp Status.
* `poll` — Create a group poll/vote.

---

## 📥 Media Downloaders

* `fb` — Download Facebook media.
* `apk` — Download APK files via Aptoide.
* `igdl` — Download Instagram videos/reels.
* `igdl4` — Instagram downloader variant.
* `igdl2` — Instagram downloader variant.
* `ig3` — Instagram downloader variant.
* `tiktok` — Download TikTok videos.
* `ttdl1` — TikTok downloader variant.
* `ttdl2` — TikTok downloader variant.
* `ttdl3` — TikTok downloader variant.
* `song` — YouTube search and MP3 playback.
* `video` — Download YouTube videos.
* `yts` — Search videos on YouTube.
* `ytpost` — Download a YouTube community post.
* `wallpaper` — Search for high-quality wallpapers.
* `wpdown` — Download wallpapers.

---

## 🎨 Image & Creative Tools

* `attp` — Create animated text stickers.
* `colorize` — Add color to black-and-white images.
* `rmbg` — Remove image backgrounds.
* `removebg` — Remove image backgrounds.
* `logo` — Create professional logos with multiple styles.
* `genlogo` — Generate professional logos.
* `seemore` — Create read-more style text.
* `tourl` — Upload images and get a direct URL.

---

## 🔧 Utility & Owner Tools

* `github` — Fetch GitHub user profile information.
* `screenshot` — Take a full-HD screenshot of a website.
* `dp` — Save a WhatsApp profile picture.
* `unblock` — Unblock a user.
* `setvv` — Set a custom VV trigger.
* `vv` — Use the configured VV trigger.
* `pky` — React to a specific WhatsApp Channel message.
